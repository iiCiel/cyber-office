## Goal
A pixel-art browser game where you live a real day as a junior security analyst: walk the office, read real-looking email, dig through logs, deal with coworkers, and watch your choices play out. Not a quiz and not a wall of text. Built in public as a portfolio piece for internship applications.

## What each run does
⛔ HARD RULES (Soliman, Oct 31/Nov 1). 1) CCDC and CPTC must be REALISTIC, HANDS-ON SIMULATIONS like the real competitions, never multiple choice as the core. 2) They must LOOK like the real tools, not like generic "AI-made" dark-card UI. Soliman played the current CCDC and said it "looks terrible, looks so AI made". Before building any screen, LOOK at real screenshots (WebSearch / WebFetch image pages, docs, GitHub READMEs, blog posts) of the real thing and copy their layout, density, fonts and colours: pfSense web GUI (dashboard, Firewall > Rules tables, Status > System Logs), Windows Server desktop / Server Manager / Active Directory Users and Computers / PowerShell window, Linux terminals (real prompts, real `top`, `journalctl`, `ss -tulpn` output), the CCDC scoreboard/scoring engine (e.g. Aeolus, ScoreStack, the NCCDC scoring pages), Splunk / Security Onion / Wazuh / Kibana log views, and for CPTC the Kali desktop, Burp Suite, nmap/Metasploit/sqlmap output and real pentest report templates. Screens should be dense, functional and tool-like (tables, tabs, status lights, real window chrome), not rounded marketing cards.
3) CCDC is a FULL SIMULATION against OTHER TEAMS: a live scoreboard with several competing teams (scores move in real time as they get attacked or lose services), a red team that attacks continuously in waves, a white team, injects arriving over time, and above all HUGE REALISTIC LOG VOLUMES: the player opens a SIEM/log viewer and faces hundreds of thousands to millions of log lines (auth failures, web access logs, firewall drops, Windows event logs) with search/filter, where real attacks are buried in noise and must be found by searching/grepping/filtering, not read from a short list. Generate this procedurally (seeded) so there is no giant file. A player should be able to feel the "2.3 million logs, someone is in, find out how" moment.
4) Multi-device: firewall (pfSense-style GUI + shell), Windows AD/DC, Windows workstations, Linux web/mail/db, …
