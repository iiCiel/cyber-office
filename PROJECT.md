## Goal
A pixel-art browser game where you live a real day as a junior security analyst: walk the office, read real-looking email, dig through logs, deal with coworkers, and watch your choices play out. Not a quiz and not a wall of text. Built in public as a portfolio piece for internship applications.

## What each run does
⛔ HARD RULE (Soliman, Oct 31, after a whole 5-hour window was wasted on multiple-choice quizzes): CCDC and CPTC must be REALISTIC, HANDS-ON SIMULATIONS — exactly like the real competitions. NEVER multiple-choice questions as the core mechanic. If you catch yourself building "pick A/B/C" buttons for the main gameplay, STOP — that is the wrong thing and wastes his usage.

HOW IT MUST WORK:
- CCDC (blue team, TEAM competition with ROLES): the player moves between MULTIPLE real devices, each with its OWN working simulated terminal — bash on the Linux boxes (web/mail/db), PowerShell on the Windows/Active Directory box (the DC), and a pfSense-style RULE EDITOR for the firewall. The player actually TYPES commands (or clicks a command onto the command line) to inspect and harden each box — the same scripted/whitelisted terminal engine the Red Team ENGAGEMENTS already use (src/game/engage.js + EngageScene.js — REUSE and EXTEND it, don't reinvent). Scored services (web/mail/DNS/DB) go UP or DOWN based on what the player actually does at the terminal. A live red team probes at the end. Build the role seats (firewall/network, Windows+AD, Linux/services, web+database, incident-response/injects+captain): each role owns its devices and has its own first-15-min checklist. Injects can stay as written tasks, but the core defending is done at real terminals, not by picking answers. Multiple company scenarios over time.
- CPTC / pentest (red team): a Kali-style attacker terminal (assessor@kali:~$) where the player actually enumerates and exploits a fictional target with typed commands and canned-but-realistic output (reuse the engagement terminal), THEN writes the report from what they found. Not a quiz about pentesting — the pentest itself is played.
- TIMED MODE: a live visible countdown (clockSeconds already in the data) for the advanced variant; a guided/untimed mode stays available.

Everything stays fictional/canned (RFC-5737 doc IPs, *.example hosts, nothing executed) — this is…
